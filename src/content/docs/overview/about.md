Euodos is a custom Android ROM **based on [LineageOS](https://lineageos.org)**. It starts from LineageOS and adds its own settings, features and fixes.

## Principles

- **Close to AOSP / LineageOS**: we stay as close to upstream as possible to make updates easy.
- **Transparency**: all code and documentation are versioned and publicly reviewed.
- **Simplicity**: step-by-step documented installation and clear settings.

## Relationship with LineageOS

| | LineageOS | Euodos |
|---|---|---|
| Base | AOSP | LineageOS |
| Tracked branch | `lineage-xx.x` | Same branch, with extra patches |
| Devices | Official list | Subset (see [Devices](/devices/)) |

:::note
Euodos is neither affiliated with nor endorsed by LineageOS. All names and trademarks belong to their respective owners.
:::

## Release channels

Builds are published on several channels:

- **stable**: tested, recommended for daily use;
- **beta**: features under test, some bugs possible;
- **nightly**: automated build, for testers only.
