**ADB** (*Android Debug Bridge*)
: Outil en ligne de commande pour communiquer avec un appareil Android allumé.

**Bootloader**
: Programme qui démarre le système. Il doit être déverrouillé pour installer une ROM.

**Fastboot**
: Mode et outil permettant de flasher des partitions.

**Recovery**
: Mini-système de maintenance servant à installer des zips et réinitialiser l'appareil.

**ROM**
: Système d'exploitation complet installé sur l'appareil.

**Sideload**
: Installation d'un zip depuis l'ordinateur via `adb sideload`.

**OTA** (*Over The Air*)
: Mise à jour reçue directement sur l'appareil.
