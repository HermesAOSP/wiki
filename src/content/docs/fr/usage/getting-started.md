Après le premier démarrage, l'assistant de configuration te guide. Voici quelques réglages à regarder ensuite.

## Réglages Euodos

Les options propres à Euodos se trouvent dans *Paramètres → Euodos*.

| Réglage | Description |
|---|---|
| Thème | Clair, sombre ou automatique |
| Barre d'état | Icônes, batterie, horloge |
| Gestes | Actions personnalisées |

## Applications

Euodos n'est pas livrée avec une boutique d'applications propriétaire. Tu peux installer [F-Droid](https://f-droid.org) pour des applications libres.

## Mises à jour

Active les notifications de mise à jour pour être prévenu des nouvelles versions : voir [Mises à jour](/fr/installation/updating/).
