**ADB** (*Android Debug Bridge*)
: Command-line tool to talk to a running Android device.

**Bootloader**
: Program that starts the system. It must be unlocked to install a ROM.

**Fastboot**
: A mode and a tool used to flash partitions.

**Recovery**
: Small maintenance system used to install zips and reset the device.

**ROM**
: The complete operating system installed on the device.

**Sideload**
: Installing a zip from the computer with `adb sideload`.

**OTA** (*Over The Air*)
: An update received directly on the device.
