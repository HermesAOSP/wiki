After the first boot, the setup wizard guides you. Here are a few settings to look at next.

## Euodos settings

Euodos-specific options live in *Settings → Euodos*.

| Setting | Description |
|---|---|
| Theme | Light, dark or automatic |
| Status bar | Icons, battery, clock |
| Gestures | Custom actions |

## Apps

Euodos ships without a proprietary app store. You can install [F-Droid](https://f-droid.org) for free software apps.

## Updates

Enable update notifications to be told about new releases: see [Updating](/en/installation/updating/).
